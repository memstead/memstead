Return graph health. Typed payload on `structured_content`; text chunkable past `token_budget` via `chunk`. Default: summary counts (`orphans_by_schema`/`communities_by_schema`), node/edge totals, distributions, `writable_mems`/`read_mems`, `default_writable_mem` (omitted-`mem` target), `mem_schemas`. `include` drills in — keys: `orphans`, `stubs`, `most_connected`, `missing_fields`, `stale`, `dangling_links`, `tags`, `missing_required_outgoing`, `constraints`, `conformance`, `integrity`, `config`, `anchors`, `friction` (refusal counts), `open_questions` (per-mem unknowns; negatives separated, capped), `stale_derivations` (edges whose target moved), `checks` (check-state counts + independence), `signals` (declared signals above `none`: value, level, contributors), `labelling` (grounded labels + evidence), `ledger` (FOLDER mem's ledger vs files; git-branch absent, not clean). `missing_fields` adds `issues[]` with `code` beside `missing`. `config` = the `include_config` projection. `conformance` lints entities into `findings` `{id, axis, code, detail}` + `body_observations` (undeclared body content; says if it survives a write), against `target_schema` or each pin; `integrity` adds `DANGLING_LINK`/`ORPHAN_STUB`. `dangling_links` lists refs lacking files. `tags` aggregates into `tag_distribution` (`limit`-capped), `tag_distribution_folded`, `untagged_entities`. `missing_required_outgoing` lists unsatisfied blocks. `constraints` lists standing violations. `anchors` adds per-mem `resolved`/`drifted`/`recheck`/`unresolvable` (artifact gone)/`unobserved` (not measured)/`dangling` (entity gone) + `entity_end_unreconciled` + `population`. Unknown keys emit `UNKNOWN_INCLUDE_KEY`; `limit` caps at 10 (>100: `LIMIT_CLAMPED`). Warnings: see instructions. Pass `mem` to scope to one mem (rosters stay global; `dangling_links`/`warnings` filter too). `include_config: true` adds `mutations` (`require_notes`), the opaque `plugin` map, per-mem `mems` (`origin`, `vcs` `gitdir`/`worktree`/`head`, `write_guidance`, `extra`).
