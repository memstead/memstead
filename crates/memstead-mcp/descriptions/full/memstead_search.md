Search entities by text and structural filters. Dual channel: rendered markdown plus a typed envelope on `structured_content`, one stable shape, every key present: `{ _total, _returned, _offset, _total_tokens, hits[], facets, warnings }`; each hit: `score`, `score_breakdown`, `matched_terms`, `expansion`, `origin` (trust class), `snippet`. `warnings` is `[]` when nothing warned; `score_breakdown` and `matched_terms` are `null` on a metadata-only call (no `query`; hits score zero), `expansion` on a primary hit, `snippet` where no text matched. A page is bounded by `token_budget` (default 12000); an overflowing page trims with `SEARCH_RESULTS_TRUNCATED` (`kept`/`budget`); `_total` stays full; page with `offset`. `query.any` ORs keyword variants, `query.not` excludes, `query.phrase` matches adjacency, `query.field` restricts to one field. `expand_via` (relationship types) walks the graph; reached hits carry `expansion` (`via_direction`, score decayed 0.5^depth); `direction` (out|in|both) narrows each hop. `facets` count by_type, by_mem, by_level, by_status, by_confidence, by_subsection, by_expansion. Sub-heading matches carry `heading_path`. `stub: true|false` filters stubs (with `entity_type` it flags `STUB_FILTER_EXCLUDES_ALL`). `filters` takes `filterable: equality` fields; one code per outcome: `FILTER_TYPE_SCOPED` (applied, type-narrowed), `FIELD_NOT_FILTERABLE` (ignored, never emptied), `UNKNOWN_FILTER_KEY` (ignored), `INVALID_ENUM_VALUE` (matches nothing, `details.allowed`). `related_to`: proximity-ranked neighbourhood, bounded by `NEIGHBOURHOOD_CAPPED`. `range_filters` takes `filterable: range` fields (`min_<field>`/`max_<field>`/`<field>_before`/`<field>_after`), same contract: `RANGE_FILTER_KEY_MALFORMED`, `RANGE_FILTER_TYPE_SCOPED`, `UNKNOWN_RANGE_FILTER_FIELD`, `FIELD_NOT_RANGE_FILTERABLE`. An unknown `mem` refuses `UNKNOWN_MEM`; an empty result is a valid mem with none. A failing mem index surfaces `SEARCH_MEM_INDEX_UNAVAILABLE` (`details.mem`/`details.reason`). Omit `query` for a pure metadata filter.
