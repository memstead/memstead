Memstead gives AI agents a typed, validated model of a project — plain markdown in git, validated on every write against a schema you control. New here? Start with the tutorial, then see [Skills](skills/) for what you actually run day to day — before diving into the concept and reference layers.

- [Author a schema](guides/author-a-schema/) — scaffold a custom schema and pin a mem to it.
- [Publish a mem](guides/publish-a-mem/) — share a mem through the memstead.io registry.
